# Обслуживание v46 — 2026-10-06

Принятая v46 подключена к механике обслуживания одного, двух или трёх сотрудников за общим столом. Заказчик может оплатить себя и товарищей; героиня может предложить напитки одному или всем и угостить. Согласие, отказ и отсрочка независимы. Предложения, ответы и оплата показываются в облачках.

Гостевой напиток стоит $2: $1.50 редакции, $0.50 героине. Собственный напиток героиня выбирает отдельно и оплачивает сама. Если она не хочет пить, четвёртый бокал и её питьё не исполняются. Старое совместное питьё за разными столами отключено. Деньги списываются только по подтверждённому исполнению, потребление учитывается один раз.

Источник, диапазон и хеши — release.json. Проверки: 29 контрактных тестов; шесть вариантов на реальных GLB; точная backend сборка в отдельном браузере, без модельных запросов; независимое ревью. Исторические общепроектные проверки не проходят из-за удалённой старой библиотеки. Новые ассеты прошли бюджетный gate; большой motions.glb имеет предупреждение размера, без morph targets.

Production app.js собран узким graft поверх фактически опубликованных байтов: сохраняются остальные phone/wardrobe/privacy патчи. backend/frontend/pages имеют отдельные baseline hashes. Исходники main отстают от некоторых уже опубликованных патчей; browser source delta содержит только обслуживание, director сохраняет точный ранее работающий live baseline. Не считать произвольную полную пересборку эквивалентной production bundle.

Кандидаты remote: service-v46-20261006-v01 и service-v46-frontend-20261006-v01. Активация и опубликованная доставка подтверждаются отдельными activation.json / publication.json. До их появления статус — подготовлен.

Откат: guarded rollback-remote.py возвращает только собственные service/Caddy указатели; директорские семь модулей возвращаются из baseline только при совпадении новых хешей. Каноническое состояние, ключи, ledger и память не заменяются старым checkpoint. После реального использования новых контрактов сначала остановить выбор новых обслуживаний и согласовать миграцию, не откатывать деньги.
